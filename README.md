# NYC EMS Analytics

A large-scale data analytics portfolio project built using Microsoft
Fabric, PySpark, SQL, DAX and Power BI.

## Project Overview

This project analyses NYC EMS Incident Dispatch Data from 2019 to 2025.

The project demonstrates:

- Large-scale data ingestion and transformation
- Medallion architecture using Bronze, Silver and Gold layers
- PySpark data engineering
- SQL analytics
- Power BI semantic modelling
- Population standard deviation
- Upper and lower statistical control limits
- Anomaly detection
- Time-series forecasting

## Dataset

- Source: NYC Open Data
- Dataset: EMS Incident Dispatch Data
- Dataset ID: `76xm-jjuj`
- Period: 2019–2025
- Columns: 31
- Raw data files are excluded from this repository because of their size
